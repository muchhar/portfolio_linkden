# bharatmuchhar.com — Portfolio

Personal portfolio website of **Muchhar Bharat**, Algorithmic Trading Developer
(NinjaTrader · MT4/MT5 · TradingView · cTrader).

Built with React + Vite.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Output goes to `dist/`. Deployed on Vercel (framework preset: **Vite**,
build command `npm run build`, output directory `dist`).
